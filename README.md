# Gestão de Medicamentos Contínuos e Controle de Estoque Familiar

Projeto desenvolvido para a Atividade de Estudo Programada (AEP) do 4º Semestre.

## Alinhamento ODS
Este projeto está alinhado ao **ODS 3 - Saúde e Bem-Estar** da ONU, buscando garantir o acesso seguro ao tratamento contínuo, reduzindo erros de medicação e promovendo o bem-estar dos pacientes e tranquilidade de seus familiares.

## Lista de Requisitos Funcionais

1. **RF01 - Cadastro de Medicamentos:** O sistema deve permitir o cadastro de medicamentos, com nome, quantidade inicial de comprimidos disponíveis, quantidade utilizada em cada dose e os horários das doses diárias.
2. **RF02 - Sistema de Lembretes:** O sistema deve gerar lembretes e notificações nos horários configurados para a administração de cada medicamento.
3. **RF03 - Confirmação de Dose:** O sistema deve permitir que o usuário confirme que tomou o medicamento em uma determinada dose, efetuando a baixa no sistema.
4. **RF04 - Controle Automático de Estoque:** O sistema deve reduzir automaticamente o estoque do medicamento correspondente e calcular quantos dias de tratamento ainda restam logo após a confirmação da dose pelo usuário.
5. **RF05 - Alerta de Recompra:** O sistema deve alertar o usuário proativamente quando a quantidade disponível em estoque representar 5 dias ou menos de tratamento.
6. **RF06 - Gestão Familiar:** O sistema deve permitir que familiares ou responsáveis acompanhem as informações de estoque e rotina de doses, desde que possuam autorização prévia do usuário.
7. **RF07 - Ajuste Manual de Estoque:** O sistema deve permitir que o usuário ajuste manualmente o estoque de um medicamento em caso de nova compra ou correção de contagem.
